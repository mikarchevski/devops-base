### Dockerfile

Главный файл, который описывает сборку образа, надо уметь написать докерфайл + знать директивы и что они делают.

Вот основные:

- `FROM`
- `RUN`
- `COPY`
- `ADD`
- `WORKDIR`
- `ENV`
- `ARG`
- `EXPOSE`
- `CMD`
- `ENTRYPOINT`
- `USER`

### Контекст сборки

Что учитывается при сборке образа, какие файлы могут попасть туда.

### Слои и кэширование

### Multi-stage build

Продвинутая практика написания докерфайла, которая позволяет сильно сократить размер образа.

### Best practice'ы

Вообще стоит изучить все лучшие практики написания докерфайла. Их примерно 13 штук, кстати есть ролик →

### Registry

Это связующее звено между сборкой и деплоем. **Очень важно для CI/CD**: пайплайн собрал образ, **положил** в registry, а дальше условный **Kubernetes** его оттуда забирает. Понимание registry + тегирование + версионирование образов — это то, что превращает просто разрозненные знания о технологии в DevOps-видение.

### Docker Compose

*Инструмент для запуска нескольких контейнеров одной командой*

В реальности приложение — это не один контейнер. Это минимум приложение + база данных, а чаще приложение + база + кэш + nginx + мониторинг.

Compose позволяет описать всю эту связку декларативно и поднимать/гасить **одной командой**.

## Практика

### Развернуть приложение

1. Взять приложение, которое осталось после практики в линуксе
2. Обернуть его в контейнеры
3. Поднять контейнеры и проверить, что приложение работает корректно

> Тут **самое главное** — КАЖДУЮ непонятную вещь разбирать.

### Docker Compose

1. Всё то же приложение засунуть в docker compose
2. Проверить, что контейнеры работают, всё работает корректно

### Мониторинг-стек

**Prometheus + Grafana + Node Exporter**

Три сервиса в compose. Prometheus собирает метрики с Node Exporter, Grafana рисует дашборды.

Одновременно учит Docker Compose и знакомит с мониторингом. Можно добавить cAdvisor для метрик самих контейнеров.

### Поднять nginx

Но не просто `docker run nginx`, а примонтировать свой `nginx.conf` через **bind mount**, отдавать свою статику, настроить проброс портов.

### Экспериментировать

Докер открывает дверь в мир экспериментов. Можно очень много всего быстро поднимать — ломать — тестировать. Здесь насколько хватит фантазии. Опять же нейронки в помощь для генерации заданий.
