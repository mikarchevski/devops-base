##  Как пользоваться этим репозиторием

1. **Двигайтесь по порядку.** Не перескакивайте на Kubernetes, не разобравшись с основами Linux, сетей и Docker.
2. **Читайте с оглавлением.** В каждом файле есть подробное содержание с якорными ссылками для быстрой навигации.
3. **Делайте практику.** В каждом разделе есть блок "Практика" — обязательно выполняйте эти задания, теория без рук в DevOps не работает.
4. **Готовьтесь к собесам.** В конце каждого раздела собраны самые популярные вопросы с реальных собеседований.
