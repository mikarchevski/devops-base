## Теория

### Архитектура

Здесь надо понимать, как кубер работает, из чего состоит.

**Control Plane:**
- API Server
- etcd
- Scheduler
- Controller manager
- Cloud Controller manager

**Worker node:**
- kubelet
- container runtime
- kube-proxy

---

### Основные сущности

Здесь надо сразу учить команды `kubectl`.

- Pod
- Deployment
- DaemonSet
- StatefulSet
- ConfigMap
- Secret
- Job
- CronJob

Здесь надо понимать, что для чего используется + как их писать.

---

### Сеть

Самая сложная тема внутри кубера, на её понимание может уйти значительное время.

**Можно разделить на 2 части:**

**Под капотом:**
- CNI-плагины
- Kube-proxy
- CoreDNS
- Работа сети на уровне нод

**Настройка через манифесты:**
- Service
- Ingress
- NetworkPolicy
- CNI-конфиг

---

### Хранилище

Тоже важная тема:
- PV
- PVC
- StorageClass

А так же виды доступа (**Access Mode**)

---

### Helm

**Helm** — пакетный менеджер Kubernetes. Как `apt` для Linux, только для кластера. Helm используется почти везде.

- Helm chart'ы
- values'ы
- template'ы

и всё что связано с командами хелма

---

### Развертывание

Изучить способы развертывания кубера:
- через `kubeadm`
- через `kubespray`
- `managed kubernetes`

---

### Продвинутые вещи

Важно, база продвинутых вещей:
- **RBAC**
- **HPA**

А дальше в целом получается развилка и идти можно куда угодно, кому что больше нравится, основные направления такие:
- **Операторы**
- **ServiceMesh** (Istio/Linkerd)
- **бэкапирование etcd**
- **GitOps** - ArgoCD, Flux
- **Multi-cluster'ные стратегии**
- **Траблшутинг на уровне кластера**
